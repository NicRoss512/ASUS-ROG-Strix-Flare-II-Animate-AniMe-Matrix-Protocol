# Flare Screen — первая экспериментальная версия

Захват X11 → 312 монохромных LED ASUS ROG Strix Flare II Animate.
Целевая среда: Arch Linux / X11. Python 3.10+.

## Установка на Arch

Распакуй архив в постоянный каталог, открой терминал в `flare-screen`:

```bash
sudo pacman -S --needed python python-pip libusb libxcb libxkbcommon-x11 xcb-util-cursor
python -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
sudo install -m 644 72-rog-flare-animate.rules /etc/udev/rules.d/
sudo udevadm control --reload-rules
sudo udevadm trigger
```

Переподключи клавиатуру. Приложение запускай из своей графической сессии **без sudo**:

```bash
./run.sh
```

Не устанавливай одновременно `opencv-python` и `opencv-python-headless` в эту venv.
Если pip не находит wheel для текущего Python Arch, понадобится поддерживаемая версия Python
или системные пакеты; пришли полный вывод ошибки установки.

## Первый запуск — безопасная проверка

1. Отправка на клавиатуру по умолчанию выключена, даже после загрузки настроек.
2. Выбери «Все LED», яркость 10–25%, нажми «Старт»: проверь предпросмотр.
3. Включи «Отправлять на клавиатуру». Должны загореться все LED.
4. Проверь «Один LED» и индексы 0, 1, 310, 311; затем «Сканирование».
5. Если ориентация/адресация верна, выбери «Экран» и нужный монитор.
6. Оставь поле области пустым для всего монитора либо введи `x,y,width,height`.
   Отрицательные координаты поддерживаются. Можно выделить область мышью (Esc — отмена).
7. Начни с 15 FPS. Увеличивай частоту только после проверки стабильности.

Геометрия адресов основана на физической карте исходного репозитория.
Относительный вертикальный шаг по умолчанию 0.5, сдвиг ряда 0.5. Это
приближение физических расстояний, не измеренная калибровка: корректируй по фото/тестовой сетке.
Усреднение — Gaussian blur + билинейная выборка в центрах LED. Гамма > 1 осветляет полутона.
Сглаживание по времени 0 отключено; 0.5 сильнее подавляет мерцание, но добавляет инерцию.
Предпросмотр LED отображает итоговые байты яркости без автоматического усиления.
При захвате самого окна приложения будет возникать рекурсивная картинка: перенеси окно
за пределы захватываемой области/на другой монитор.

## Видео

«Открыть видео…», затем «Старт». Повтор включён по умолчанию. Скорость привязана
к монотонному времени и FPS из файла, устаревшие кадры пропускаются. Звука нет.
В этой версии остановка/следующий старт **перезапускают видео с начала**:
настоящая пауза и перемотка пока не реализованы. Лучше использовать видео с постоянным FPS;
VFR, GIF, потоковые URL и точная синхронизация временных меток не гарантированы.
Доступные форматы зависят от кодеков OpenCV.

## Сохранение

Кнопка «Сохранить настройки» пишет `~/.config/flare-screen/settings.json`.
Путь видео и область сохраняются. Отправка HID никогда не включается автоматически.
«Гасить при остановке» также применяется при закрытии и отключении отправки.
При неожиданном завершении/выдёргивании USB очистка не гарантируется.
При ошибке HID повтор подключения выполняется примерно каждые 2 секунды.

## Проверки

```bash
.venv/bin/python -m unittest -v test_core
```

Автотесты: контрольные индексы физической карты, пакет 1024 байта, белый/чёрный
кадр, яркость/инверсия, варианты масштаба и поворота, градиент.
В среде разработки проверены вычислительное ядро и синтаксис; работа реального
HID, X11-захвата и GUI на твоём Arch требует проверки на устройстве.

## Неполадки

- `interface 4` не найден: проверь `lsusb -d 0b05:19fc`, USB и модель клавиатуры.
- Permission denied: проверь udev, переподключи устройство, убедись, что запущено
  из активной локальной графической сессии (правила `uaccess`).
- X11-захват: проверь `echo "$DISPLAY"` и `echo "$XDG_SESSION_TYPE"`.
- Qt xcb: установи перечисленные системные зависимости; запускай `./run.sh`.
- Несовпадение области при HiDPI: launcher отключает Qt-масштабирование, чтобы
  выделение и MSS использовали одинаковые пиксельные координаты X11.
- Не запускай одновременно другие программы управления AniMe Matrix.
- Если клавиатура зависла: отсоедини оба USB-разъёма на 10–15 секунд.

## Протокол / источник

https://github.com/NicRoss512/ASUS-ROG-Strix-Flare-II-Animate-AniMe-Matrix-Protocol

VID:PID `0b05:19fc`, interface 4. Ровно 1024 байта: `60 81 00 00`,
312 значений яркости и 708 нулей. Дополнительный Report ID не добавляется,
как описано автором исходного исследования. Поведение используемого hidapi backend
нужно подтвердить на конкретном устройстве; код проверяет длину записи.
Никаких control transfers, команд от ноутбуков и записи во встроенную память.
Описанный автором способ не означает гарантированной безопасности для любой прошивки.

## Файлы

- `app.py` — Qt GUI, рабочий поток, захват X11 и видео, HID-управление.
- `core.py` — карта, геометрия, обработка и упаковка протокола.
- `test_core.py` — тесты без GUI и клавиатуры.
- `run.sh` — запуск в venv с нативными координатами X11.
- `72-rog-flare-animate.rules` — доступ к hidraw без root.
